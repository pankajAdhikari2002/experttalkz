About this course

This course dives deep into the psychology behind user interfaces. We move beyond simple aesthetics to understand how users think, feel, and behave. You will learn to construct user journeys that are not only intuitive but delightful.

Through a series of real-world projects, you will redesign an existing mobile application, create a design system from scratch, and implement micro-interactions that elevate the overall experience. By the end, you'll have a portfolio-ready case study.
